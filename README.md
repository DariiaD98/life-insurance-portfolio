# Дарья Дихтяренко — агент по страхованию жизни

Одностраничное сайт-портфолио в стиле [isadeburgh.com](https://isadeburgh.com): большое имя в шапке,
бегущая строка, коллажи из полароидов, программы страхования, таймлайн и контакты.

Чистые HTML / CSS / JS — без сборки и зависимостей. Откройте `index.html` в браузере
или запустите локальный сервер:

```bash
python3 -m http.server 4321
```

- `index.html` — весь контент сайта
- `css/styles.css` — стили
- `js/main.js` — анимации (лоадер, параллакс, бегущая строка, переключение программ)
- `img/` — фотографии (заглушки с Pixabay, кроме главного фото)
